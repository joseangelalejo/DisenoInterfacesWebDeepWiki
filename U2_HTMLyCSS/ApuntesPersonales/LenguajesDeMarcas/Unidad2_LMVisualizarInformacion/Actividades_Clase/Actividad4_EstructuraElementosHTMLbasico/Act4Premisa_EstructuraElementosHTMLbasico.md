# Objetivo de la actividad

El objetivo es poner en práctica el uso de enlaces, navegación interna y elementos multimedia en HTML, aplicando estilos básicos para mejorar la presentación y estructura del documento.

## Instrucciones

1. Crea un documento HTML que incluya diferentes tipos de enlaces: uno externo a una página web que abra en una nueva pestaña y otro que dirija a una parte concreta del mismo documento utilizando un identificador (id), por ejemplo, al final del documento.

2. Inserta contenido multimedia en la página: al menos una imagen, un vídeo y un audio. Asegúrate de que todos los elementos sean visibles y funcionen correctamente.

3. Utiliza la etiqueta `<iframe>` para incrustar un vídeo de YouTube o mostrar otra página web dentro de la tuya.
4. Modifica el tamaño de los elementos multimedia mediante atributos.
5. Centra los elementos utilizando `<div>`.
6. La entrega debe ser un archivo .zip que incluya todo el proyecto completo, es decir, el archivo .html junto con todas las imágenes, vídeos y audios utilizados. Asegúrate de que al descomprimir la carpeta, la página funcione correctamente y se visualicen todos los elementos.
