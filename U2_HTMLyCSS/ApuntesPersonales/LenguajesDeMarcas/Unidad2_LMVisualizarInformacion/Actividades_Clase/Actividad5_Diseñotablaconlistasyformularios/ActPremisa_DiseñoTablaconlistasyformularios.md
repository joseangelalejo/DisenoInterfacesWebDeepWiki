# Actividad 5: Diseño de Tabla con Listas y Formularios en HTML

Crear una página HTML que contenga una tabla con distintos tipos de contenido y estilos básicos.

- Instrucciones:
  - Crea un archivo .html
  - Diseña una tabla que cumpla las siguientes condiciones:
  - Debe tener fondo de color, tamaño definido de celdas y espacio entre las celdas.
  - La primera fila debe contener una celda que agrupe 3 columnas (usando colspan="3") con el título “Sección de Listas”.
  - La segunda fila mostrará los encabezados: “Lista ordenada”, “Lista desordenada” y “Lista de definiciones”.
  - La tercera fila incluirá un ejemplo de cada tipo de lista (ol, ul y dl).
  - La cuarta fila  mostrará una celda que agrupe 3 columnas (usando colspan="3") con el título “FORMULARIO”.
  - La quinta fila mostrará los encabezados: “Login” y "selecciona una opción".
  - La sexta fila incluirá un ejemplo de Login (incluye un menú desplegable)  y un ejemplo de selección con input="radio"

- Aplica un estilo sencillo con CSS interno (en la etiqueta `<style>`):
  - Separación entre celdas (border-spacing).
  - Tamaño mínimo de las celdas (min-width, min-height).
  - Bordes visibles.

Entrega:
Sube el archivo .html terminado comprobando que se visualiza correctamente en el navegador y que las listas y el formulario aparecen integrados dentro de la tabla.
