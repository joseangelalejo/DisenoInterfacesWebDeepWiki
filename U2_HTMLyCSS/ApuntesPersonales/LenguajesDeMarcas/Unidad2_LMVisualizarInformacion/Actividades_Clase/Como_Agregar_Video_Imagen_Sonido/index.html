Usamos Usamos img src para insertar una imagen que está en nuestro ordenador o en una URL

Si indicamos la ruta de manera incorrecta la imagen no se mostrará.
En caso de no mostrarse podemos indicar un texto alternativo con el atributo alt


Usando los atributos width y height podemos ajustar el tamaño de la imagen, reescalandola. Si solo indicamos width o height, el otro atributo se ajustará de manera que la imagen no se deforme.

Si la imagen se representa como una foto, se utiliza "figure" junto con "figcaption" para añadir un título debajo de la imagen


Si queremos crear un vínculo dentro de una imagen, tenemos que meter la etiqueta imagen dentro de una etiqueta vínculo href


Para insertar un video usamos la etiqueta video, dentro de la cual podemos usar la etiqueta source para indicar la ruta del video y su tipo.

Para poder reproducir el vídeo completamos la etiqueta con el atributo controls, que permite pausarlo, reanudarlo y controlarlo.

Si queremos que se reproduzca automáticamente usamos autoplay muted. Y si queremos que se reproduzca en bucle usamos loop.


Para reproducir audio es exactamente igual que el vídeo pero con la etiqueta audio.


Si queremos centrar un audio o un vídeo u otro elemento, utilizamos la etiqueta div englobando a la etiqueta video/audio


La etiqueta iframe se utiliza para insertar contenido de otras páginas web dentro de la nuestra. Es especialmente útil para incrustar videos de plataformas como YouTube.


Si queremos agregar un audio de otra página, utilizamos la etiqueta iframe.
