# Actividad 19: Transformación de XML a HTML y TEXTO mediante XSLT

A partir de un documento XML proporcionado, crear una hoja de estilos XSLT que transforme su contenido en una página HTML bien formada y en una página en TEXTO PLANO.

PARA EL HTML: En la salida, cada nodo "titulo" deberá mostrarse como un elemento de una lista ordenada y, dentro de cada uno, sus datos asociados como año, género y demás información deberán aparecer en una lista desordenada.

PARA EL TEXTO PLANO: Mostrar el título, genero, año, duración y protagonistas, ordenando la salida por título Alfabéticamente.

Entregar un único documento PDF que incluya capturas de pantalla donde se visualice el XML cargado en el navegador mostrando correctamente la transformación a HTML, así como el código de la hoja de estilos XSLT utilizada.
