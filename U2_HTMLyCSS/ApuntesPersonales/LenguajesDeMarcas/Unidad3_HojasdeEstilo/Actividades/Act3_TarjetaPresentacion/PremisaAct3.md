# Premisa de Actividad 3 - Tarjeta de Presentación CSS interno

Debes crear una tarjeta de presentación utilizando HTML y CSS con los estilos incrustados dentro del propio archivo. La tarjeta tendrá un tamaño fijo y contendrá un título, un subtítulo, un texto descriptivo y un botón. El fondo de la pantalla debe ser de un solo color. La tarjeta debe llevar una imagen de fondo con transparencia aplicada solo a la imagen usando la propiedad opacity en una capa independiente. La tarjeta debe incluir borde, bordes redondeados, relleno interno, outline separado del borde y una sombra exterior. El objetivo es practicar el modelo de cajas, el uso de capas, la transparencia con opacity y los fondos en CSS.

- Debes usar un único archivo HTML con los estilos dentro de la etiqueta `<style>`.
- Debes usar un div independiente para aplicar opacity solo a la imagen de fondo.
- Debes usar obligatoriamente: width, height, padding, border, border-radius, outline, outline-offset y box-shadow.
- Debes usar una imagen de fondo con background-image.
- El texto debe ser totalmente legible, sin transparencia.
- La tarjeta debe quedar centrada en la pantalla.

- Entrega:
  - Debes entregar un único archivo .html
  - El diseño final debe ser visual, limpio y bien alineado
