# Premisa de actividad 2

Crea un archivo HTML, aplica CSS interno para dar estilo con las pseudoclases vistas en clase(`:hover` y `:focus`) y las presentadas en las diapositivas de la unidad.

- Las pseudoclases a utilizar son:
  - `:hover`
  - `:focus`
  - `:checked`
  - `:valid` / `:invalid`
  - `:out-of-range` / `:in-range`
  - `:link` / `:visited`
  - `:optional` / `:required`
