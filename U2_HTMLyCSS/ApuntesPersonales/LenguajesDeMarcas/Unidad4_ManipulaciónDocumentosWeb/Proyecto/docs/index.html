Catálogo de Películas

Proyecto educativo de Lenguajes de Marcas

Proyecto educativo del módulo de Lenguajes de Marcas que consiste en un catálogo dinámico de películas con manipulación de datos JSON y CSS. Aplicación web que permite explorar, filtrar y visualizar información de películas de forma interactiva.

Stack Tecnológico

HTML5 CSS3 JavaScript Vanilla JSON Responsive Design

Características principales

  • Catálogo dinámico cargado desde JSON
  • Búsqueda y filtrado de películas
  • Interfaz responsiva y moderna
  • Manipulación DOM con JavaScript vanilla
  • Sistema de wishlist y favoritos
  • Página de detalles completa
  • CSS3 con Grid y Flexbox
  • UX optimizada para móvil y desktop
