# Premisa Actividad 7: Integración de RSS en una Web de Noticias

Crear una página web que muestre contenido dinámico utilizando fuentes RSS reales y presentarlo con un diseño moderno basado en tarjetas de noticias.

REQUISITOS FUNCIONALES

- Integrar al menos 3 feeds RSS reales y diferentes.
Ejemplo:
- Feed de xataka: `https://www.xataka.com/feedburner.xml`

REQUISITOS DE DISEÑO

- Diseño visual moderno y atractivo.
- Estilo similar a Google News o Flipboard.
- Uso de tarjetas o bloques para cada noticia.
- Separación clara entre las distintas fuentes RSS.
- Maquetación limpia y bien organizada (uso correcto de HTML y CSS).

ENTREGA

- Un único Archivo HTML
- La página debe cargar correctamente los feeds y mostrarlos de forma dinámica.
