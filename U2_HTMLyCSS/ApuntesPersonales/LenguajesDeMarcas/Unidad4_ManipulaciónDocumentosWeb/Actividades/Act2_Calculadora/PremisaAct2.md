# Premisa Actividad 2: Calculadora Web

A partir de la actividad de la calculadora de la unidad anterior, utiliza JavaScript para habilitar la funcionalidad de la calculadora. La calculadora debe permitir a los usuarios realizar operaciones básicas como suma, resta, multiplicación y división.

Realiza la tarea mediante JavaScript interno, es decir, incluyendo el código JavaScript dentro de la misma página HTML utilizando la etiqueta `<script>`.
