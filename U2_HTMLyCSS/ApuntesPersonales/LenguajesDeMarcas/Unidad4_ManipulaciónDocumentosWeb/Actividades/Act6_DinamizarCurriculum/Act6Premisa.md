# Actividad 6 - Agregar elementos dinámicos a tu currículum

Realiza una mejora de tu currículum (el de la entrega Actividad 7) en HTML incorporando un panel de configuración que permita modificar su apariencia dinámicamente mediante JavaScript y manipulación del DOM. El menú lateral debe mostrarse o ocultarse a través de un botón (tema) que debe incorporar la página que muestra el currículum.

Debes crear un menú lateral o superior similar a un panel de personalización donde el usuario pueda:

- Cambiar el tipo de fuente de los títulos del currículum.
- Cambiar el tamaño de los títulos.
- Cambiar el color de los títulos.
- Cambiar el tipo de fuente de los párrafos.
- Cambiar el tamaño de los párrafos.
- Cambiar el color de los párrafos.
- Cambiar el color principal del tema (por ejemplo, color de acentos, líneas o elementos destacados).
- Cambiar el color de fondo del currículum completo.
- Activar y desactivar un modo oscuro mediante un botón o interruptor.

Todos los cambios deben aplicarse en tiempo real utilizando manipulación del DOM con document.getElementById(), document.querySelectorAll(), .style, .value, setAttribute() u otros métodos vistos en clase.

Entrega el archivo HTML funcional donde se pueda interactuar con el menú y comprobar que todas las opciones modifican correctamente el currículum.
