## Orden recomendado para el examen

1. Leer el enunciado y detectar las secciones de la página.
2. Revisar el wireframe/mockup y decidir la estructura HTML.
3. Crear HTML semántico y accesible.
4. Aplicar estilos base, reset y variables.
5. Resolver la distribución principal con Flexbox o Grid.
6. Añadir responsive design con media queries.
7. Revisar formularios, estados, imágenes y contraste.
8. Comprobar la página en distintos tamaños.
