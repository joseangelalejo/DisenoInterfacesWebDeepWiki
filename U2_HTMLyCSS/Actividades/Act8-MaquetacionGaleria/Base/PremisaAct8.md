# Premisa Act8 - Maquetación Galería

A partir de la estructura HTML proporcionada y la imagen de referencia del diseño de galería, desarrolla los estilos CSS para reproducir el diseño de la galería de fotografías.

Utiliza CSS Grid para organizar los elementos de la galería.

Utiliza las propiedades grid-template-columns, grid-template-rows, grid-column y grid-row para establecer la distribución principal.

Utiliza grid-auto-flow y position para organizar los elementos de la galería.
