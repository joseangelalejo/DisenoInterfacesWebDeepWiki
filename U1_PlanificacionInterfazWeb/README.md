## Cómo estudiar la unidad

1. Leer los apuntes personales.
2. Revisar las diapositivas del profesor.
3. Relacionar los conceptos de planificación con las actividades posteriores de HTML y CSS.
4. Aplicar primero la estructura y el objetivo de la interfaz antes de empezar a maquetar.
