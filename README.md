# Diseño de Interfaces Web

Repositorio de apuntes, recursos, actividades y prácticas de **Diseño de Interfaces Web (DIW)** para todo el curso de 2º DAW.

El contenido se organiza por unidades. Se conservan los recursos originales del profesor y se añaden apuntes personales, cheatsheets y guías de estudio en la unidad correspondiente.

---

## Unidades

- [Unidad 1 - Planificación de la interfaz web](U1_PlanificacionInterfazWeb/)
- [Unidad 2 - HTML y CSS](U2_HTMLyCSS/)

En este repositorio se irán incorporando nuevas unidades a medida que avance el curso.

---

## Cómo usarlo

1. Entrar en la unidad que se quiera estudiar.
2. Leer el `README.md` de la unidad.
3. Consultar los apuntes y cheatsheets.
4. Practicar con las actividades originales.
5. Revisar los recursos enlazados y los apuntes personales de primero cuando corresponda.

> **Nota:** Los apuntes personales sirven como guía de estudio. En una actividad o examen siempre hay que respetar el enunciado, la estructura proporcionada y las restricciones del profesor.
